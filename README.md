# 产品作品集

总作品集网站，使用单一网页入口 `dist/index.html` 展示多个项目。

目前包含三个项目：

- ORAE 塔罗解读体验，案例已有初稿。
- 高德地图项目，等待补充案例材料。
- Arivo 视频生成团队管理网站，等待补充案例材料。

本地预览可在仓库根目录运行 `python -m http.server --directory dist 4173`，打开 `http://localhost:4173`。仓库以 Sites 作为网页托管方式，配置位于 `.openai/hosting.json`。

个人定位、项目职责、简历、联系方式，以及高德地图与 Arivo 的项目细节待补充。
