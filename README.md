# 李彤彤 · 产品作品集

统一入口为 [dist/index.html](dist/index.html)，收录 ORAE、高德地图「附近与推荐体验设计」、Arivo 视频团队工具和桌游厅四个项目，包含项目分析与站内交互展示。

- ORAE 展示 AI 产品设计、关系管理体验与复盘。
- 高德案例聚焦附近与推荐体验、商家详情和半屏交互。
- Arivo 只整理公开演示与可公开的产品取舍，并注明模拟和待验证内容。
- 桌游厅展示多人联机、原创桌游和运营管理台；运营数据与反馈留待补充。

本地预览可运行 `python -m http.server --directory dist 4173`。Sites 托管配置位于 `.openai/hosting.json`。
